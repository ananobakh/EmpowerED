# EmpowerED

**EmpowerED** is an educational initiative focused on breaking barriers to education and promoting equal access to quality education for everyone.

The project aims to raise awareness about educational inequality, encourage people to support accessible education, and highlight the importance of making learning opportunities available to all communities.

## Features

- **Home Page:** Introduces EmpowerED and its mission.
- **About Us & Our Mission:** Explains the project's values, goals, and beliefs about educational equality.
- **Fact Generator:** An interactive feature that displays facts about educational inequality and the challenges affecting access to education.

## Technologies Used

- **HTML** – Website structure and content.
- **CSS** – Styling, layout, and visual design.
- **JavaScript** – Interactive elements and functionality.

## 🎓 Background

EmpowerED was created as part of the **Girls Who Code Self-Paced Program (2023)**. The project was developed to explore how technology and digital solutions can help raise awareness about educational inequality and promote equal access to education.

The website was initially developed using **Replit** and later pushed to **Git** for version control and project management.
